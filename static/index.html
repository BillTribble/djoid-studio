How Rekordbox XML export works

        

        
      


      

        

          1. What is inside the Rekordbox XML file?
          DJOID Studio generates a Pioneer DJ / AlphaTheta spec-compliant <DJ_PLAYLISTS Version="1.0.0"> file containing three core blocks: <COLLECTION> (track file paths, BPM, Camelot Tonality, and LUFS notes), <TEMPO Inizio="..." Bpm="..." Metro="4/4"/> (exact beatgrid anchor), and <POSITION_MARK> entries for color-coded Hot Cues A–D (Num="0".."3") plus Memory Cues (Num="-1"), followed by your ordered setlist under <PLAYLISTS>.
        


        

          2. Connect the XML file in Rekordbox Preferences
          Open Pioneer Rekordbox (v6 or v7) and go to Preferences → Advanced → Database → rekordbox xml. Under Imported Library, click Browse and select the rekordbox.xml file downloaded from DJOID Studio.
        


        

          3. Reveal the XML panel in the Rekordbox sidebar
          In the left vertical icon rail of Rekordbox (Performance or Export mode), click the rekordbox xml icon (if hidden, enable View → Layout → rekordbox xml in the top menu bar).
        


        

          4. Import playlist & Hot Cues A–D to your Collection
          Expand rekordbox xml → Playlists → DJOID Studio AI Set, right-click the playlist, and choose Import To Collection. When you load any track to a deck or export to USB for CDJs/XDJs, Hot Cues A (Intro), B (Buildup), C (Drop), and D (Mix Out) and the beatgrid lock load onto your performance pads automatically.
        

      


      

        Compatible with Rekordbox 5, 6 & 7 + CDJ-3000 / XDJ
